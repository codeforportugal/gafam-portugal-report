# Design system — gafam_pt report

## Overview

Visitor mode: **Read**. Surface: static budget-meeting report (`reports/index.html`, generated by `render_html()`). World: International Typographic Style / Müller-Brockmann — objective order, modular grid, flush-left grotesque, one accent on paper/ink. No purple gradients, no warm-cream Claude look, no Inter/Roboto/Arial/system as display face, no nested card clutter, no bounce easing.

## Colors

- **Paper** `#ffffff` ground; **ink** `#111111` text.
- **Primary accent** `#c59300` for emphasis rules, focus, and the `contrato assinado` chart series.
- **Muted** `#4a4a4a` for secondary lines (must stay ≥4.5:1 on paper).
- **Rule** `#d0d0d0` hairlines between bands — not card chrome.

## Typography

- **Archivo** for display, body, and large numerals (grotesque; not Inter).
- **Space Mono** for folios, section meta, channel labels, timestamps.
- Flush-left, ragged-right. Hierarchy by scale and weight, not colour floods.
- Body measure ~65–75ch inside the reading column.

## Layout

- 12-column modular grid; baseline `--bl: 8px`; leading `--lh: 24px`; gutter 24px; side margin 32px; max width 1120px.
- Content and optional grid guides share the same `.wrap` box.
- Sections are **bands** on the grid separated by hairlines and whitespace — not stacked DaisyUI cards.
- Year totals: two asymmetric year columns with large numerals for `contrato assinado`, secondary mono-labelled rows for `pedido ao mercado` and `apoio aprovado`. Channels never sum visually.

## Elevation & Depth

Flat paper. No soft neon halos, no multi-layer card shadows. Depth = whitespace + hairline rules.

## Shapes

Square corners (`0`). Charts sit in ruled panels, not rounded metric tiles.

## Components

- Masthead title + short lead + mono generation stamp.
- Year-total composition (numerals, not dashboard stats widgets).
- Chart panels (2×2 on wide viewports) with Chart.js colours from tokens.
- Keyword lists (correspondências / rejeitadas).
- Press list (`Na imprensa`), SciPROJ note, sources, caveats, CSV/JSON footer links.
- Footer mark and license badges come from the Code for Portugal commons (`../assets/` when this repo sits in that tree, otherwise `data/brand/`). See `../DESIGN.md`.
- Text selection tinted with accent wash; `:focus-visible` outline uses primary (`#c59300`).

## Do's and Don'ts

**Do**

- Keep European Portuguese labels exactly as product constraints require.
- Treat the three money channels as parallel, never additive.
- Prefer boring CSS variables + DaisyUI CDN utilities over a build step.

**Don't**

- Nest cards or invent a purple/indigo theme.
- Use Inter, Roboto, Arial, or system-ui as the display voice.
- Add kickers/eyebrows above section headings.
- Use bounce/elastic easing.
